# Development validation

This records developer verification, not engineering approval. The pilot-release gate is still closed pending a qualified professional's independent reference review and electrician field testing.

## Automated coverage

- 54 Vitest tests: independent table-36 reference constants for B1/B2/C at 127/220 V and LN/LL, every supported temperature/grouping factor, oven and long-route cases, PE transitions, overload/I2 coordination, catalog exhaustion, unsupported inputs, precise selection boundaries, four statuses and evidence invalidation, per-alternative feasibility, conductor/cable materials, decimal-comma input, snapshot isolation, transactional persistence/migration, future records and quota failures.
- Browser regression suite on Chrome at 390 × 844: full equipment/route/safety/results journey; input preservation; save/reopen/edit/delete; complete offline reload, edit, save and PDF export; no non-GET or external installation-data requests; accessible labels/landmarks/contrast through axe; four-page report with Portuguese text and matching snapshot numbers; visible storage failures; deferred service-worker updates; rapid plan switching; current updates within one second with 4× desktop CPU throttling.
- `npm run build`, `npm run format:check`, `git diff --check` and dependency audit.

PDFs are generated by the production app and examined with Poppler (`pdftotext`, `pdfinfo`, `pdftoppm`). All pages of the long report are visually inspected for pagination, glyphs and clipping. Desktop/mobile UI is also inspected with `agent-browser`.

## Source review

The supplied standard's cover and extracted clauses establish its identity as NBR 5410:2004, corrected 2008-03-17. Ampacity, temperature and grouping tables were compared against page renders. The supplementary manufacturer guide distinguishes isolated flexible conductors from multicore flexible cable: ruleset `.2` uses the larger table-31 resistance envelope across all methods, rather than applying the smaller table-29 values to multicore cable. This conservatism and applicability to actual products still require professional review.
